# Дерево ассасина
Ассасин выбирает жертву и момент выхода: скрытность даёт крит и ×1,6, смерть возвращает тень.
Его оружие — кинжалы; дым прикрывает, кровь кровоточит, яд работает между твоими действиями.
Сейчас выпад, клык и ночной обрыв конкурируют одной цифрой; плоские пассивки не дают решения.
Дымный шаг без настоящего ухода плохо объясняет пользу; вскрытие без яда вообще недоступно.
Нельзя требовать соседний вариант тира: генератор и трата доступны по отдельности на любом пути.

## Мозговой штурм — 54 кандидата
1. Теневой выпад — одиночный вход, меткость и небольшая отрава, дороже быстрого реза.
2. Подхват кинжала — дешёвый быстрый удар; вне тени возвращает энергию.
3. Ядовитый клык — длинная доза из тени вместо быстрого добивания.
4. Перерезать путь — замедлить жертву; тень добавляет метку.
5. Двойная насечка — два слабых удара, вне тени сильнее.
6. Доза по кругу — заразить группу; слабое одиночное давление.
7. Шаг под ребро — открыть кровь, в тени сильнее; готовит будущие критические выходы.
8. Перехват кисти — атакой ослабить ответ, особенно вне тени.
9. Затаиться — сохранить работу яда, спрятаться и купить щитом время вместо удара.
10. Дымный разрез — слабая атака с уходом в тень после попадания.
11. Сменить руку — ускорение при смене атакующей кнопки вне тени.
12. Горький ответ — новая доза, вне тени ещё замедление.
13. Взять след — добивание раненой цели возвращает энергию и запускает новый выход.
14. Круг кинжалов — вне тени работать по группе вместо охоты за одним убийством.
15. Не будить яд — осторожный отравленный бросок сохраняет начальную скрытность.
16. Последний силуэт — дорогой выход по раненой цели с большим предвосхищением.
17. Ножевой шквал — три попадания, в открытом бою часть энергии возвращается.
18. Смертная доза — вложиться в длительный яд; из тени он живёт дольше.
19. Дымный шаг — уклонение, ускорение и два приёма вместо прямого удара.
20. Кража приёма — обычный сбор плюс ещё приём вне тени.
21. Удар в печень — частое одиночное добивание, тратит весь запас.
22. Неполная связка — два попадания, на полном запасе энергия вместо траты приёмов.
23. Отсечь погоню — широкое добивание, одна цель получает меньше.
24. Без развязки — сохранить пять приёмов ради усиленного одиночного удара.
25. Токсичный порез — дешёвая добавка к четырём дозам токсина.
26. Проверить дрожь — удар по созревшему яду без обновления; без яда даёт слабую стартовую дозу.
27. Разогнать токсин — продлить старую дозу, сохранив рост тиков.
28. Промыть лезвие — добавить яд, затем ослабить дозу ради энергии.
29. Глубокий прокол — сила имеющегося токсина добавляется к удару; дозу сохраняешь.
30. Мёртвый час — дым, замедление группы и продление яда вместо прямого урона.
31. Два клыка — два удара и раны для сборки приёмов и критических вскрытий.
32. Казнь — потратить приёмы и проверить настоящий порог казни.
33. Зарез по шву — добивание с критом по уже открытой ране.
34. Красная ступень — удар по ране лечит, приёмы продолжают копиться.
35. Без права на вдох — добивание оставляет долгую рану, если казни ещё нет.
36. Перепрыгнуть тело — убийство даёт два приёма для следующей жертвы.
37. Удар из тени — быстрый удар создаёт отражение даже без удачного уклонения.
38. Исчезновение — два отражения и уклонение вместо мгновенного урона.
39. Порез отражения — сохранить тени и энергию, удар слабее жертвенного.
40. Разбить отражение — отдать одну тень за более сильное попадание.
41. Свести отражения — усиленный удар со всеми повторами, затем потерять все отражения.
42. Тени вразброс — атака по группе и ещё одно отражение вместо полного расхода.
43. Чёрный флакон — кинжал со свежим крепким ядом, подготовка вскрытия.
44. Сухой надрез — использовать броню, уже разъеденную тиками, без новой дозы.
45. Вскрытие раны — выплатить силу яда × оставшиеся ходы, сохраняя сам яд и тень.
46. Настаивать — удар продлевает яд, не сбрасывая его созревание.
47. Вирулентность — прямое давление по отравленной цели, слабее по чистой.
48. Слить осадок — снять яд ради ограниченной выплаты и лечения после попадания.
49. Касание чумы — яд и слабость, тики приближают заражение.
50. Гниющая рана — второй вид тиков быстрее приводит к чуме, если цель кровоточит.
51. Заражённый круг — слабые яд и кровь на группу ради быстрого порога пяти тиков.
52. Переболеть — до чумы приближает порог, после чумы лечит.
53. Носитель — сохранить чуму и сильно ударить, обновив обе беды.
54. Сбросить лихорадку — отдать чуму ради большого лечения, щита и скрытности.

## Отбор и решения по ходам
Отброшены плоские +5%, магические лучи, одинаковые яды разных цветов, слабый дым без выплаты.
«Один за другим»: вход → кровь/метка → добивание слабейшего → новая тень; босс лишает цепочки убийств.
«На виду»: вход → быстрый подхват → смена руки → круг/шквал; выбирай энергию и защиту вместо ухода.
«Долгое послевкусие»: яд → широкая доза → затаиться → бросок без раскрытия; быстрый бой не окупит дозу.
Тень: набрать дважды по два приёма или атаковать чаще; потратить всё либо удержать пять.
Токсин: складывать дозы либо продлевать старый яд, не сбрасывая рост его тиков.
Клинок: рана → критическое добивание; казнить сейчас либо собрать больше приёмов для высокого порога.
Фантом: собрать отражения атакой/уклонением; сохранить постоянные повторы либо пожертвовать запасом.
Отравитель: доза → созревание и разъедание → вскрытие; продление конкурирует с новой дозой.
Чумной: два вида бед → пять тиков → чума; сохранить лечение от тиков или сбросить чуму ради спасения.
На 1–3 уровне один выбранный навык плюс обычный удар; с уровня 4 любые первые два выбора атакуют.
Пять слотов: оставь вход/генератор и выплату, остальные места меняй под одиночную цель или группу.
Баланс серий учитывает: скрытность усиливает все удары действия, энергия стоит ×2,5, крит вскрывает кровь.
Проверены 201096 префиксов смешанных выборов: с уровня 4 даже пять последних активных дают ≥2 атаки.
Проверены девять сценариев тени, приёмов, отражений, продления яда, вскрытия и сброса чумы.
Ограничение движка: вес light жёстко задаёт тряску 0,05; данные навыка не позволяют её отключить.
