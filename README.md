# Кузница Шагов (Forge of Steps) — Alpha 2.0

Пошаговая PvE-игра в браузере: один герой, походы с риском потерять добычу, таймлайн инициативы и намерения врага, генерируемый лут, кузница, 5 классов, поэтапный путь (подкласс на 30 уровне, профессия на 60, у каждого своя механика) и 24 профессии, 4 региона и финальный босс.

## Аудит

- `node tools/audit-core.js`: случайные бои, карьеры, битые сохранения, сюжет и проверка всех данных.
- `tools/audit-ui.js`: обход настоящего интерфейса и целые походы, сохранение на это время отключено.
- `node tools/shot.js сценарий.js`: снимки игры в отдельном браузере с пустым профилем.

## Как запустить
Открой `index.html` двойным кликом. Сборка, установка и интернет не нужны (без сети шрифты заменятся системными).

Либо через локальный сервер:

```bash
node tools/serve.js
```

Адрес: http://localhost:4173. Инструменты разработчика включаются параметром `?dev=1`.

## Проверки
```bash
node tests/run.js
```

```bash
node tools/sim.js 4
```

Первая команда запускает автотесты ядра. Вторая прогоняет бота: бои, походы и полные прохождения всех классов (число задаёт количество прохождений на класс).

## Устройство
- `js/core/talents.js`, `data.talents.js`, `data.run.js`, `data.classes.js`, `data.shop.js` — таланты, дары тропы, ядра классов, группы врагов, боссы, сеты, ультимейты и умения лавки;
- `js/core` — вся логика без DOM: бой (`combat.js`), походы (`expedition.js`), предметы и кузница (`items.js`), герой (`hero.js`), сохранения (`save.js`) и данные (`data.*.js`).
- `js/ui` — экраны (`menus.js`, `hub.js`, `battle.js`), оригинальная SVG-графика (`art.js`), сцены, частицы и звук (`fx.js`).
- Бой выдаёт очередь событий со снимками состояния, а интерфейс проигрывает её. Поэтому тот же код работает в тестах и симуляции.
- Сейвы старого прототипа переносятся при первом запуске в том же браузере и на том же адресе, а старые записи с паролями удаляются.

## Прогресс
- Тропы региона открываются по очереди (`trailClears`), босс доступен после фиолетовой тропы. Боссы статичны: `GUARDIAN_POWER` в `js/core/data.lairs.js`.
- Логова (`js/core/data.lairs.js`, `data.lairbosses.js`): один большой хозяин со стадиями и своими приёмами, ступени до 80 уровня, реликвии комплектов из 8 разных частей (бонусы 2/4/6/8), возвышение реликвий в кузнице. Сила хозяев по классам и ступеням лежит в `data.lairtune.js`: её подбирают `tools/tune-lairs.js`, `tune-lairs-fix.js`, `tune-lairs-merge.js`, проверяет `tools/balance-lairs.js`.
- Вещи разделены по классам: поле `classes` у чертежа в `data.world.js`. Индекс чертежа связан с иконкой, новые дописывать только в конец.
- Облик героя: `heroLookId`, рисует `tools/gen-looks.js`.

## Сборка героя
- Правила в `js/core/build.js`, экраны в `js/ui/build.js`, контент классов в `js/core/data.build.<класс>.js`, замысел в `docs/build-design.codex.md`.
- Очки развития: 1 за 2 уровня и по 2 за первых четырёх стражей, предел 48. На них берутся формы навыков и таланты.
- Дерево навыков: `js/core/data.tree.<класс>.js`, мозговые штурмы в `docs/tree-<класс>.md`. На каждом шаге берётся один навык, у класса три ветки, у пути две. Анимация каждого навыка описана в его поле `anim`, движок `js/stage3d/signature.js`, проверка `node tools/check-tree.js <класс>`.
- Стиль с 5 уровня, 2 формы у четырёх навыков пути, по 2 ультимейта за класс, подкласс и профессию, 5 школ талантов (у мага 6) по 11 узлов.
- Проверка контента: `node tools/check-builds.js [класс]`. Иконки ультимейтов: `node tools/gen-images.js --only=ult_`.

## История
- Сюжет лежит в `js/core/data.story.js`, логика в `js/core/story.js`, показ сцен и журнал в `js/ui/story.js`. Исходный черновик Codex: `docs/story-plan.codex.json`.
- Сцены запускаются сами по состоянию героя (`syncStoryEvents`) и идут один раз. Кадры рисует `tools/gen-story.js` по `tools/story-art.json`.

## Графика
- Бойцы нарисованы: у каждого шесть поз на одном листе (`tools/gen-sprites.js`, затем `tools/cut-sprites.js`), вторые шесть поз рисует `tools/gen-sprites-b.js`, бой показывает их в `js/stage3d/sprites.js`. Локации собраны из слоёв: `tools/gen-scenes.js`, затем `tools/cut-scenes.js`. При открытии двойным кликом браузер не даёт читать такие файлы, поэтому те же рисунки и звуки лежат скриптами в `assets/pack`: после любой нарезки запускай `node tools/pack-offline.js`.
- `js/stage3d/`: бой на Three.js. `stage.js` сцена и камера, `choreo.js` постановка навыков, `vfx.js` эффекты стихий.
- `art/*.py`: модели и анимации, собираются Blender из кода: `blender --background --python art/build_characters.py -- warrior mage`, окружение через `art/build_env.py`. После сборки: `node tools/pack-models.js`.
- `tools/gen-images.js`: арт через Codex, 257 картинок. Уже готовые пропускает, поэтому можно перезапускать. Новые картинки видны после перезагрузки страницы.
- `tools/art-preview.html?m=warrior&d=3.8&yaw=20`: просмотр модели. `tools/stage-test.js`: прогон всех навыков класса в бою из консоли браузера на `?dev=1`.

## Интерфейс
- `styles-v3.css`: кованый интерфейс поверх старых стилей. Графика из `tools/gen-ui.js` (Codex), нарезка `tools/cut-ui.js` в `assets/ui`. Значки подменяются в функции `icon()`.

## Звук
- `js/ui/audio.js`: записи с вариациями, эхо, музыка и окружение. `art/build_audio.py` готовит банк из `art/audio-src` (запуск через Blender). Источники и лицензии: [assets/audio/CREDITS.md](assets/audio/CREDITS.md). Только CC0.
